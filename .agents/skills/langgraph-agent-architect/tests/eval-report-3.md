## Исправление по результатам RED

В серии до правки два прогона S9 начали проверку пути до представления трёх режимов. Один ответ сразу сообщил, что `specs/missing-brief.md` отсутствует, не спросив, какой режим выбирает пользователь; ответ и трасса сохранены в [S09-main-rep01-treatment](results/refactor-3/S09-main-rep01-treatment.md). Второй сбой сохранён в [S09-main-rep02-treatment](results/refactor-3/S09-main-rep02-treatment.md).

Причина — неоднозначное толкование глагола «проектируй» как состоявшегося выбора режима, хотя пользователь не назвал ни один из трёх режимов. В Skill добавлено явное условие: выбор считается сделанным только когда пользователь называет режим или выбирает его после меню. Добавлена структура первого ответа: перечислить режимы, порекомендовать один, спросить выбор и остановиться; указанный путь проверять только на следующем ходе. Это узкое дополнение не меняет правила поиска кандидатов и S12.

Для воспроизводимости отдельно обновлена подготовка TREATMENT в runner: полный текущий текст Skill включается в `AGENTS.md` до начала диалога. Итоговый PASS основан на фактических ответах и трассах новых независимых LLM-сессий, а не на статическом анализе.

## Публикационная проверка и ограничения

Трассы проверены на секреты, абсолютные локальные пути и вызовы инструментов записи. Локальные пути удалены; содержимое ответов GitHub и локальных инструкций Superpowers в JSONL скрыто, при этом имена инструментов, аргументы, порядок и статусы сохранены.
