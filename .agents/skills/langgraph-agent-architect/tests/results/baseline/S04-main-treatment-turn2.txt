Предлагаю сначала выбрать основу архитектуры:

- **LangGraph** — граф задаёт, кто может делегировать и сколько раз; координатор проверяет результат и завершает работу по явным условиям. Рекомендую этот вариант, если ограничение делегации должно быть строгим.
- **Deep Agents** — делегирование специализированным агентам встроено; меньше собственной оркестрации, но контроль процесса требует отдельной проработки.
- **Гибрид** — Deep Agents для планирования и делегирования, LangGraph для задач с жёсткими маршрутами и лимитами.
