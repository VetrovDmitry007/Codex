Какой режим выбрать?

- **Проектирование с нуля** — разработать архитектуру процесса подтверждения и отмены.
- **Аудит архитектуры** — проверить существующую схему; для этого нужны её описание или ссылка.
- **Модификация архитектуры** — добавить подтверждение человека перед отправкой в действующую схему.

Рекомендую **проектирование с нуля**: пока есть только требование, без описания существующей архитектуры. Какой режим выбираете?
