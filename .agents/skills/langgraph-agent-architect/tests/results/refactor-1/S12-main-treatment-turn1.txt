В локальной папке графа не нашёл: доступны только инструкции. Пришлите его файл, схему или код.

Есть три режима:

- **Аудит** — найти проблемы и дать рекомендации.
- **Модификация** — предложить исправленную архитектуру графа.
- **Проектирование с нуля** — спроектировать новый граф.

Для вашей задачи рекомендую **модификацию**. Инструкция по LangGraph требует согласовать режим, даже если вы просите выбрать его самостоятельно. Какой режим выбираете?
