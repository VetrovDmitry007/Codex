Зафиксировал требования: принять заявку, однократно проверить заполненность и вернуть результат; без LLM и памяти.

Для такого линейного процесса подходят два варианта:

- **Обычная функция** — минимум компонентов и сложностей. Рекомендую её, если LangGraph не обязателен.
- **LangGraph `StateGraph`** — явные узлы «принять заявку → проверить → вернуть результат», но для одной проверки добавляет накладные расходы.

LangGraph — обязательное требование?
