# S07-main-rep01-treatment

- Сценарий: `S7`
- Вариант: `treatment`
- Модель: `gpt-6-luna` (high)

## Ход 1 — запрос пользователя

У меня есть существующий LangGraph-граф, хочу обсудить его маршрутизацию.

## Ход 1 — ответ агента

Для существующего графа есть три режима:

- **Аудит** — проверить текущую маршрутизацию и выявить проблемы.
- **Модификация** — обсудить, как изменить маршруты.
- **Проектирование с нуля** — спроектировать новую архитектуру.

Для обсуждения уже существующей маршрутизации я рекомендую **аудит**. Какой режим выбираете?

## Ход 2 — запрос пользователя

Выбираю режим «Аудит архитектуры».

## Ход 2 — ответ агента

В рабочей папке нет кода или описания графа — только инструкции, поэтому пока нечего проверять. Пришлите фрагмент с `State`, узлами, `add_edge` и `add_conditional_edges` (а также `Command` или `Send`, если используете) и опишите, что в маршрутизации вызывает сомнение. Для аудита этого фрагмента достаточно; остальной граф я не буду оценивать без его описания.

## Ход 3 — запрос пользователя

У узла `analyze` есть статический переход к `archive` и он может вернуть `Command(goto="review")`. Почему после analyze идут обе ветки?

## Ход 3 — ответ агента

`Command(goto="review")` добавляет динамический переход, но не отменяет статическое ребро `analyze → archive`. Поэтому после `analyze` LangGraph планирует обе ветки; документация прямо описывает такое поведение ([Graph API: `Command`](https://github.com/langchain-ai/docs/blob/main/src/oss/langgraph/graph-api.mdx#L988-L1056)).

Если `review` и `archive` должны быть взаимоисключающими, уберите статическое ребро и пусть `analyze` возвращает `Command(goto="review")` либо `Command(goto="archive")`. Альтернатива — убрать `Command` и выбрать одну ветку через `add_conditional_edges`.

- **Проблема:** статическое и динамическое управление маршрутом используются одновременно.
- **Критичность:** средняя: обе ветки могут выполнить работу, которая должна быть взаимоисключающей.
- **Последствие:** запускаются и `review`, и `archive`.
- **Рекомендация:** оставить для `analyze` один способ маршрутизации.
- **Вердикт:** **требует доработки** для этого фрагмента; остальной граф не проверен.
