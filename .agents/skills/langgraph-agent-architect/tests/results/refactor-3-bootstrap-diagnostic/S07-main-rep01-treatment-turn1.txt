Для существующего графа подходят три режима:

- **Аудит архитектуры** — проверю текущую маршрутизацию и дам замечания с рекомендациями.
- **Модификация архитектуры** — разберём, что стоит изменить в маршрутах, и согласуем обновлённую схему.
- **Проектирование с нуля** — предложу новую архитектуру графа.

Для начала рекомендую **аудит**: он поможет понять, как маршрутизация работает сейчас и где есть пространство для изменений. Какой режим выбираете?
