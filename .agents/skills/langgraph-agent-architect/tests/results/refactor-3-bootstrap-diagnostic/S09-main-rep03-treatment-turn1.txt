Для архитектурной работы есть три режима:

- **Проектирование с нуля** — разработать архитектуру по требованиям и подготовить архитектурную спецификацию.
- **Аудит** — проверить уже существующую архитектуру и описать проблемы и рекомендации.
- **Модификация** — изменить действующую архитектуру и обновить её спецификацию.

Рекомендую **проектирование с нуля**: вы указали предыдущую спецификацию требований `specs/missing-brief.md`, по которой нужно спроектировать архитектуру. Какой режим выбираете? После выбора сначала проверю именно этот файл.
