Для задачи подходят три режима:

- **Проектирование с нуля** — построить новую архитектуру.
- **Аудит архитектуры** — найти проблемы в существующем графе и предложить исправления.
- **Модификация архитектуры** — спроектировать изменения действующего графа.

Рекомендую **модификацию архитектуры**. Инструкция для LangGraph требует, чтобы вы явно выбрали режим; просьба выбрать за вас этого требования не заменяет. Как только выберете, изучу граф и подготовлю конкретное решение. Рабочая область доступна только для чтения, поэтому смогу дать рекомендации в чате, но не менять файлы.
