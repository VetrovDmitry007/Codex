Для архитектурной задачи есть три режима:

- **Проектирование с нуля** — разработать новую архитектуру по требованиям.
- **Аудит архитектуры** — проверить существующую архитектуру или граф.
- **Модификация архитектуры** — изменить уже действующую архитектуру.

Рекомендую **проектирование с нуля**: вы просите разработать архитектуру по предыдущей спецификации. Какой режим выбираете? Указанный файл проверю после выбора.
