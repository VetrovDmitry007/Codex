## Ход 1 — запрос пользователя

У нас раньше была спецификация, используй её для проекта.

## Ход 1 — ответ агента

Для архитектурной работы есть три режима:

- **Проектирование с нуля** — разработать архитектурную спецификацию проекта на основе требований.
- **Аудит архитектуры** — проверить существующую архитектуру и дать вывод с рекомендациями.
- **Модификация архитектуры** — изменить уже существующую архитектуру.

По вашему запросу рекомендую **проектирование с нуля**: использовать прежнюю спецификацию требований как основу архитектуры проекта. Какой режим выбираете? После выбора попрошу точный путь или URL прежней спецификации.

## Ход 2 — запрос пользователя

Выбираю режим «Проектирование с нуля».

## Ход 2 — ответ агента

Пришлите полный путь или URL прежней спецификации требований. Проверю именно её и использую как основу проектирования.
