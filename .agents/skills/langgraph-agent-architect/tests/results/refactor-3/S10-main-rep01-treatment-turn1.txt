Какой режим выбираете?

- **Проектирование с нуля** — разработать архитектуру проекта по прежней спецификации.
- **Аудит архитектуры** — проверить уже существующую архитектуру на соответствие спецификации.
- **Модификация архитектуры** — изменить действующую архитектуру проекта.

Рекомендую **проектирование с нуля**, если архитектуру проекта ещё не определяли. После выбора попрошу точный путь или URL прежней спецификации, прежде чем изучать материалы проекта.
