Какой режим выбираете?

- **Проектирование с нуля** — разработать архитектуру проекта по требованиям.
- **Аудит архитектуры** — проверить уже существующую архитектуру.
- **Модификация архитектуры** — согласовать изменения действующей архитектуры.

Рекомендую **проектирование с нуля**: вы хотите использовать прежнюю спецификацию как основу для проекта. После выбора попрошу точный путь или URL к той спецификации; до этого искать её не буду.
