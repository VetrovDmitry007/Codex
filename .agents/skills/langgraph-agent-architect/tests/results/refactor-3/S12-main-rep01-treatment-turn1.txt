Для работы с графом есть три режима:

- **Проектирование с нуля** — подготовить архитектуру нового агента.
- **Аудит архитектуры** — проверить существующий граф и описать проблемы с рекомендациями.
- **Модификация архитектуры** — пересмотреть существующую архитектуру и предложить обновлённую.

Для вашей задачи рекомендую **модификацию архитектуры**: вы хотите проверить действующий граф и исправить его устройство. Какой режим выбираете?
