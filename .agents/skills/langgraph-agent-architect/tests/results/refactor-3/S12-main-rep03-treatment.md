## Ход 1 — ответ агента

Для этой задачи есть три режима:

- **Проектирование с нуля** — создать архитектуру нового агента.
- **Аудит архитектуры** — проверить граф и выдать проблемы с рекомендациями.
- **Модификация архитектуры** — разобрать действующий граф и предложить обновлённую архитектуру.

Рекомендую **модификацию архитектуры**, поскольку вы просите исправить существующий граф. По правилам этой задачи я не могу выбрать режим за вас, даже если вы поручаете мне выбрать самому. Работа будет только в чате: локальные файлы менять нельзя.

Какой режим выбираете?
