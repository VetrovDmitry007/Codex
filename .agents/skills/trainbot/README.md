# TrainBot — Yandex Direct Optimization Skill (planning)

Рабочий каталог будущего Agent Skill для продвижения сайта https://trainbot.ru/ через Яндекс Директ.

## Цель

Максимизировать количество посетителей сайта, привлечённых через Яндекс Директ, в рамках согласованного бюджета и ограничений.

## Входные данные

- Информация о сайте TrainBot, продукте и целевой аудитории.
- Спецификация целей, рекламного бюджета и ограничений.
- Данные Яндекс Директа и веб-аналитики (по мере подключения).

## Ожидаемый результат

Обоснованное задание на оптимизацию рекламных кампаний: конкретные действия, приоритеты, риски, проверяемые критерии результата.

## Статус

Начальная структура. Файл `SKILL.md` и правила работы ещё не подготовлены. Изменения в рекламном кабинете автоматически не выполняются.
