# TrainBot — специализированный Skill для SEO и AI-поиска

**Сайт:** https://trainbot.ru/  
**Основной навык:** [SKILL.md](SKILL.md)  
**Согласованный стратегический трек:** органический SEO Яндекса и Google **без платной рекламы**; дополнительный трек — AI-видимость (Алиса AI, Google AI, Bing/Copilot, ChatGPT Search).

## Назначение

Skill помогает анализировать реальную индексируемость сайта, органический спрос, качество полезных страниц, их попадание в AI-ответы и фактические переходы на сайт. Главная метрика — **уникальные посетители из органического поиска**, а не клики или цитирования. Он составляет обоснованные спецификации/задания и поддерживает каноническую дорожную карту; не меняет сайт и поисковые кабинеты без разрешения.

## Статус

Редакция 2026-11-04 переводит Skill на бесплатное органическое SEO/AEO/GEO. Профиль продукта основан на исторических публикациях; текущие условия и работоспособность нужно перепроверять. Статические проверки инструкций не заменяют **независимые LLM-тесты**, их выполнение должно подтверждаться отдельно. Доступ к частным SEO-данным и API не предполагается.
