# TrainBot — специализированный Skill для Яндекс Директа

**Сайт:** https://trainbot.ru/

**Основной навык:** [SKILL.md](SKILL.md)

**Цель:** максимизировать число уникальных посетителей сайта из Яндекс Директа при согласованных бюджете и ограничениях. Skill анализирует сайт и рекламные данные, затем создаёт обоснованное техническое задание на оптимизацию. Рекламные кампании без отдельного согласия не изменяет.

## Файлы

- [SKILL.md](SKILL.md) — правила работы специализированного навыка.
- [references/optimization-task-template.md](references/optimization-task-template.md) — шаблон ТЗ.
- [tests/evaluation-cases.md](tests/evaluation-cases.md) — сценарии тестирования.

## Связанные инструкции

- [TrainBot Skill Development](../../../instructions/trainbot-skill-development.md) — правила разработки с использованием Superpowers, GitHub и профильных SEO/РРС Skills.
- [Правила взаимодействия](../../../instructions/interaction-rules.md).

## Статус

Первичная версия создана. Реальные рекламные выгрузки, спецификация ограничений и независимые LLM-прогоны тестов пока отсутствуют. Функциональность аналитики и интеграции с API не реализована; навык задаёт процедуру агентного анализа и подготовки ТЗ.
