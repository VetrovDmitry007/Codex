## Задания

### DIRECT-001 — Название конкретного изменения

- **Приоритет:** P0 (измерение/критическая проблема) / P1 (обоснованное улучшение) / P2 (эксперимент).
- **Объект:** кампания / группа / объявление / запрос / посадочная страница; ID и URL, если известны.
- **Наблюдение:** проверяемые факты с периодом, значениями и источниками.
- **Причина:** подтверждена или гипотеза (с указанием уверенности).
- **Изменение:** конкретная настройка/фраза/объявление/страница; текущее и предлагаемое состояние.
- **Ожидаемое влияние:** на посетителей из Директа, стоимость посетителя и качество; направление изменения и допущения, без гарантированных цифр.
- **Риски и ограничения:** возможная потеря релевантного трафика, обучение стратегии, неполная статистика и т. п.
- **Как проверить:** конкретный KPI, сравнимые периоды, сегментация, критерий приемки, дата проверки после достаточного набора данных.
- **Статус согласования:** только предложение / явно согласовано / выполнено / проверено.

## Контроль качества отчёта

- Не заменять посетителей кликами, визитами или переходами в Telegram.
- Не складывать уникальных посетителей разных кампаний без проверки пересечений.
- В каждом пункте отделять факты от предположений.
- Сначала исправлять ошибки измерения, затем предлагать изменения расходов и настроек.
- Если нет достаточных данных, не формировать команды на изменение ставок, бюджета и отключение объявлений.
