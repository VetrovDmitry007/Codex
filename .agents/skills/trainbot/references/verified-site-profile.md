# TrainBot: проверенный профиль сайта для рекламного анализа

**Дата фиксации:** 2026-11-04. **Предмет проверки:** опубликованная информация официального сайта, а не фактическая работоспособность функций или текущие настройки Директа.

**Источники и свежесть**
- [S1 — официальная главная страница](https://trainbot.ru/): содержимое доступно через веб-индекс, последний указанный обход ~3 месяца до даты фиксации. Прямую загрузку текущей версии проверить не удалось; изменения после последнего обхода возможны.
- [S2 — инструкция TrainBot (PDF, версия 2.0, 13.11.2024)](https://trainbot.ru/static/DOCS/Описание%20работы%20с%20TrainBot.pdf): ссылка размещена на S1. Документ устаревающий; использовать для объяснения механики, но не для неподтверждённых текущих обещаний.
- [S3 — Telegram @best_train_bot](https://t.me/best_train_bot): целевая ссылка кнопки «Перейти к боту» на S1.
- **Статус:** подтверждено, что сведения опубликованы на официальном сайте; их текущая актуальность, качество работы, цены и показатели кампаний **не подтверждены**.

## 2. Условия, которые нельзя без проверки превращать в рекламу

- S1 использует выражения «гарантированный выбор нижних полок», «мгновенные уведомления», «гарантированные места». Это **маркетинговые заявления сайта**, а не доказательства безусловной доступности или гарантий. Рекламный текст не должен утверждать гарантированную покупку/бронь или 100% появление мест.
- S1 содержит бесплатный пробный вариант, ориентировочные тарифы «79 руб./день» и «250 руб./неделю», предложение «100 рублей на счёт» и оговорки мелким шрифтом. **Цены, бонус и бесплатные лимиты — изменяемые условия:** прежде чем включать их в объявление, запросить подтверждение у владельца и проверить текущие условия в боте.
- FAQ S1 указывает действие брони 15 минут и возможность повторного бронирования при положительном балансе. **В рекламу не переносить без перепроверки текущей механики и исключений.**
- S2 датирован **2024-11-13**. При расхождении S2 с текущим ботом, условиями и сайтом использовать актуальные проверенные условия, а расхождения документировать.
- Не утверждать официальное партнёрство с РЖД; сервис позиционируется как самостоятельный инструмент.

## 3. Семантические направления — только гипотезы, НЕ собранные ключевые слова

На основе опубликованных функций возможны группы намерений:

1. «нет билетов на поезд», «билеты появились» → отслеживание свободных мест;
2. «как найти свободное место в поезде» → поиск;
3. «нижние полки», «места рядом», «в одном купе» → подбор мест;
4. «бот для бронирования билетов на поезд», «автоматическое бронирование» → функциональный запрос.

**Нельзя утверждать:** частотность, CPC, объём спроса, лучшую конверсию или пригодность формулировок без Вордстата и отчёта реальных поисковых запросов. Широкий запрос «купить жд билет» не равен намерению воспользоваться ботом; отдельно проверять релевантность.

## 5. Обязательное применение

Перед составлением конкретных объявлений сравнить каждый рекламный тезис с S1/S2 и текущими подтверждениями владельца. Отдельно проверить изменяемые условия. Для оценки эффективности использовать показатели реального аккаунта, а не содержимое сайта. При отсутствии данных о рекламе давать **гипотезы для проверки**, не предлагать необоснованные изменения бюджета и минус-фраз.
