# Yandex Direct Traffic Optimizer

Рабочий каталог для разработки Agent Skill по оптимизации рекламных кампаний Яндекс Директа для сайта https://trainbot.ru/.

## Цель

Максимизировать количество посетителей сайта, привлекаемых через Яндекс Директ, с учетом рекламного бюджета и заданных ограничений.

## Планируемые входные данные

- Информация о сайте TrainBot и его предложении.
- Спецификация целей, бюджета и ограничений.
- Данные рекламных кампаний Яндекс Директа и аналитики.

## Планируемый результат

Обоснованное задание на оптимизацию Яндекс Директа: изменения, приоритеты, ожидаемые эффекты, риски и критерии проверки.

## Статус

Каталог создан. Правила и структура Skill будут разработаны отдельно. Пока автоматическое изменение рекламных кампаний не предусмотрено.
