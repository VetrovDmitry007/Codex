# MCP Prompt `assess_portfolio_quality`

**Статус:** проектный текст, сохранён для последующего внедрения. **Реализация и регистрация MCP Prompt на сервере отложены по решению пользователя.**

**Назначение:** качественная оценка облигационного портфеля с числовым обоснованием, без нового интегрального балла.

**Планируемый параметр:** `account_id` — идентификатор анализируемого счёта. Текст использует уже полученные данные MCP Tools и Resources; не выполняет расчёты на сервере.

**Связанная спецификация:** [MCP-клиент BondNavigator](mcp-client-bondnavigator-2026-10-30.md), §9.20.

## Текст MCP Prompt

```text
Оцени качество облигационного портфеля счёта {account_id} для стратегии
удержания бумаг до погашения/применимой оферты и реинвестирования выплат.
Используй факты из отчёта портфеля и доступных MCP Tools/Resources.
Не выдумывай отсутствующие показатели и не пересчитывай готовые скоринги.

Сопоставь доходность к погашению/оферте, отдельно купонную доходность,
четыре риска (кредитный, финансовый, структурный, ликвидность),
концентрации по выпуску, эмитенту и группе, а также сроки и структуру
выплат, если эти данные доступны.

Для финансового скоринга учитывай текущее значение, отчётный период,
готовую характеристику финансовой динамики, а также значение прошлого
отчёта и изменение между отчётами, если сравнение корректно.
Не смешивай динамику внутри отчёта и изменение между отчётами.

Для каждого эмитента при наличии учитывай только последнюю
проанализированную новость: готовый скор от −50 до +50, готовую
суммаризацию из 3–4 коротких предложений, дату публикации и период
анализа. Не декомпозируй скор на события и не анализируй новости заново.

Рассмотри все позиции; подробно опиши лишь существенные для качества
портфеля. Оцени баланс доходности, риска и влияния каждой такой бумаги
на портфель с учётом её доли и концентраций. Отметь достоинства
и недостатки без ярлыков «хорошая»/«плохая».

Дай итоговую оценку качества портфеля: высокая, средняя или низкая.
Обоснуй её конкретными числовыми данными, выдели главные сильные
стороны и проблемы, существенные позиции и ограничения исходных данных.
Если достоверной информации недостаточно, скажи об этом явно.
Не вводи интегральный числовой скор портфеля, фиксированные пороги
или новые веса показателей.
```
