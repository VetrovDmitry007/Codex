# Виджет выбора станций TrainBot — функциональные требования

- **Дата:** 2026-11-12
- **Статус:** частично согласовано; UX отдельных экранов продолжается, реализация не начиналась
- **Сценарий:** создание подписки «Отслеживание» (расширение на редактирование обсуждается отдельно)
- **Техническая архитектура:** [station-widget-architecture-2026-11-12.md](./station-widget-architecture-2026-11-12.md)
- **Независимо от календаря:** это самостоятельная спецификация, не модификация календарной

## Цель

Упростить выбор станции (города) отправления и назначения в подписке «Отслеживание», не заменяя существующий механизм поиска станций РЖД и FSM.

## Утверждённые UX-решения

1. **«Откуда» и «Куда» — две самостоятельные формы**. Отдельное открытие и отдельный выбор; визуальный компонент может переиспользоваться.
2. **Базовый экран — компактный вариант 1:** четыре кнопки популярных станций (состав списка ещё не утверждён) и кнопка «Другие станции».
3. Нажатие **«Другие станции» показывает алфавит** — не переводит автоматически на обычный ввод текста в чате. Каждое нажатие на букву **добавляет её к набираемому названию станции**. Под сеткой букв отображается это слово, справа от него располагается кнопка **«Поиск»**. Только её нажатие запускает поиск станций по набранному тексту; результаты затем предлагаются для выбора.
4. **Узкая форма:** пользователь попросил уменьшить ширину. Прототип использует 260 логических пикселей; точное значение ещё не утверждено, проверить читаемость на клиентах Telegram.
5. Сохранение одной станции не должно автоматически устанавливать другую.

## Прототип алфавитного экрана — предложение для обсуждения

Заголовок «🚉 Откуда» / «🚉 Куда», кнопка возврата, компактная сетка русского алфавита, 6 колонок; ниже — строка набранного текста и кнопка «Поиск» (в примере набрано «МОС»):

```text
┌──────────────────────────┐
│ ‹  🚉 Откуда              │
│ Наберите станцию         │
│ А  Б  В  Г  Д  Е        │
│ Ё  Ж  З  И  Й  К        │
│ Л  М  Н  О  П  Р        │
│ С  Т  У  Ф  Х  Ц        │
│ Ч  Ш  Щ  Ъ  Ы  Ь        │
│ Э  Ю  Я                 │
│ МОС             [Поиск] │
└──────────────────────────┘
```

Макет иллюстрирует виджет, а не подтверждённый рабочий Telegram UI. Буквы набираются **нажатием кнопок**, а не системной клавиатурой — у Telegram HTML Widgets нет обычного текстового ввода. **Предложение, ещё не утверждено:** рядом со строкой или отдельным компактным рядом добавить «⌫» (удалить букву) и «Очистить». Результат поиска и обработку пустого запроса согласовать отдельно.

## Требует согласования

- Как показывать результаты **после нажатия «Поиск»**: ограниченный список, пагинация или дополнительная фильтрация; правила пустого запроса/нулевых результатов и коррекции слова.
- Источник и порядок популярных станций (четыре названия в прототипе лишь примеры).
- Нужна ли ручная текстовая альтернатива для старых клиентов Telegram и для длинных списков станций (рекомендуется сохранить существующий ввод).
- Повторное использование виджета при редактировании подписки.
- Точная ширина и внешний вид на узких мобильных экранах.

## Границы

- Не менять обработчики календаря, бизнес-логику подписок, API РЖД, БД или рабочий код без отдельного поручения.
- Не переносить поиск станций из backend во встроенный произвольный JS-справочник.
